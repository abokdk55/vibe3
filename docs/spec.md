# 안병옥 강사 랜딩페이지 업그레이드 MVP 기획서

## 1. 서비스 한 줄 정의와 주 사용자

### 서비스 한 줄 정의

안병옥 강사의 AI·무역 실무 교육 커리큘럼을 소개하고, 기관/개인 강의 문의를 접수·관리하는 강사 비즈니스용 웹 서비스입니다.

### 주 사용자

- 교육 담당자: 학교, 기관, 기업에서 AI·디지털·무역 실무 강의를 섭외하려는 담당자
- 일반 학습자: 커리큘럼을 확인하고 강의 상담을 신청하려는 개인
- 관리자: 강사 또는 운영 담당자로서 커리큘럼 콘텐츠와 접수된 문의를 관리하는 사용자

## 2. 화면 목록

| 화면 | 목적 | MVP에서 필요한 주요 요소 |
| --- | --- | --- |
| 첫화면 | 강사의 신뢰도와 강의 분야를 빠르게 전달하고 문의 신청으로 유도 | 히어로 소개, 프로필 이미지, 핵심 경력 수치, 추천 대상, 커리큘럼 요약, 경력/수상/자격, 문의 CTA |
| 목록 | 사용자가 제공 가능한 강의 커리큘럼을 한눈에 비교 | 커리큘럼 카드 목록, 분야 태그, 난이도, 소요 시간, 요약 설명, 상세 화면 이동 |
| 상세 | 특정 커리큘럼의 학습 내용과 적합 대상을 자세히 확인 | 커리큘럼 제목, 핵심 설명, 세부 학습 내용, 추천 대상, 기대 결과, 문의 CTA |
| 등록 | 방문자가 강의 상담 또는 섭외 문의를 제출 | 이름, 연락처, 문의 내용, 봇 방지용 숨김 필드, 제출 상태 메시지 |
| 로그인 | 관리자만 문의와 콘텐츠 관리 화면에 접근 | 관리자 비밀번호 입력, 로그인 오류 메시지, 비밀번호 복구 진입 |
| 마이페이지 | 관리자 전용 운영 화면으로 문의와 페이지 콘텐츠를 관리 | 접수 문의 목록, 문의 상태 변경, 히어로 문구 수정, 연락처 수정, 커리큘럼 항목 추가/수정/삭제, 로그아웃 |

## 3. 저장해야 할 데이터 항목

### 문의 데이터

| 데이터 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | --- | --- |
| id | string | 필수 | 문의를 구분하는 고유 ID |
| name | string | 필수 | 문의자 이름 |
| contact | string | 필수 | 전화번호 또는 이메일 |
| message | string | 선택 | 문의자가 남긴 상세 내용 |
| status | enum | 필수 | 문의 처리 상태. 값: `new`, `contacted`, `done` |
| createdAt | datetime | 필수 | 문의 접수 시각 |

### 콘텐츠 설정 데이터

| 데이터 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | --- | --- |
| heroEyebrow | string | 필수 | 첫화면 상단 보조 소개 문구 |
| heroTitle | string/html | 필수 | 첫화면 메인 제목. 줄바꿈용 `<br>` 허용 |
| heroSubtitle | string/html | 필수 | 첫화면 설명 문구. 줄바꿈용 `<br>` 허용 |
| ctaLabel | string | 필수 | 대표 CTA 버튼 문구 |
| contactEmail | email string | 필수 | 문의용 이메일 주소 |
| contactPhone | string | 필수 | 문의용 전화번호 |
| curriculum | array<object> | 필수 | 커리큘럼 카드와 상세 링크 목록 |

### 커리큘럼 항목 데이터

| 데이터 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | --- | --- |
| id | string | 선택 | 커리큘럼을 안정적으로 구분하는 내부 ID |
| tag | string | 필수 | 분야 태그. 예: AI 실무, 콘텐츠, 무역 실무 |
| title | string | 필수 | 커리큘럼명 |
| level | string | 필수 | 난이도. 예: 입문, 중급, 실무 |
| hours | string | 필수 | 예상 소요 시간. 예: 2시간, 4시간 |
| summary | string | 필수 | 카드에 표시할 한 줄 요약 |
| details | array<string> | 필수 | 세부 학습 내용 목록 |
| detailUrl | string | 선택 | 상세 페이지 경로 |

### 관리자 인증 데이터

| 데이터 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | --- | --- |
| passwordHash | string | 필수 | 관리자 비밀번호 해시 |
| salt | string | 필수 | 비밀번호 해시에 사용하는 salt |
| updatedAt | datetime | 필수 | 관리자 비밀번호 마지막 변경 시각 |
| sessionToken | signed cookie string | 필수 | 관리자 로그인 세션 쿠키 |

## 4. 이번 과정에서 만들지 않을 기능

- 일반 사용자 회원가입
- 일반 사용자용 마이페이지
- 온라인 결제와 강의 예약 확정
- 캘린더 기반 일정 예약
- 이메일/SMS 자동 발송
- 실시간 채팅 상담
- 다중 관리자 권한 관리
- 강의 후기 작성/관리
- 블로그 또는 뉴스 게시판
- 커리큘럼별 파일 다운로드 관리
- 방문자 분석 대시보드
- 다국어 페이지
- 별도 모바일 앱

## 확인 질문

1. 문의 접수 후 관리자에게 이메일이나 문자 알림까지 보내야 하나요?
2. 커리큘럼 상세 페이지에는 수강 대상, 준비물, 강의 방식, 기대 결과 중 어떤 항목을 반드시 넣어야 하나요?
3. 관리자 화면을 현재처럼 비밀번호 하나로 보호하면 충분한가요, 아니면 계정 기반 로그인으로 바꿔야 하나요?
