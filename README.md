# 안병옥 강의 안내 사이트

HTML/CSS/JavaScript와 Vercel Node.js API로 구성된 강의 안내·상담 사이트입니다. 별도 프런트엔드 빌드 과정은 없습니다.

## 로컬 실행

Node.js 24와 npm을 사용합니다. PowerShell 실행 정책으로 `npm.ps1`이 차단되면 같은 명령을 `npm.cmd`로 실행하세요.

```sh
npm ci
npm run preview
```

`http://127.0.0.1:4173`에서 정적 화면을 확인할 수 있습니다. 이 미리보기는 API나 환경 변수를 읽지 않습니다. 홈페이지는 기본 안내를 표시하며 로그인·저장·상담 접수는 동작하지 않습니다.

API까지 실행하려면 `.env.example`을 `.env.local`로 복사하고 **개발 전용** 비공개 Vercel Blob 저장소 값을 설정한 뒤 `npm run dev`를 실행하세요. Vercel CLI 설치·로그인·프로젝트 연결이 필요할 수 있습니다. CLI가 운영 프로젝트를 연결하거나 환경 변수를 가져오도록 제안하면 연결 대상을 먼저 확인하세요. 세션은 Secure 쿠키를 사용하므로 HTTPS 환경에서 최종 검증하세요.

| 환경 변수 | 설정 |
| --- | --- |
| `BLOB_READ_WRITE_TOKEN` | 해당 환경의 비공개 Blob 토큰 |
| `SESSION_SECRET` | 32자 이상의 무작위 비밀값 |
| `ADMIN_PASSWORD` | 최초 관리자 비밀번호, 12~128자 |
| `RECOVERY_CODE` | 비밀번호 복구용 별도 무작위 비밀값, 32~256자 |

비밀값은 소스에 기록하지 않습니다. 새 무작위 값은 비밀번호 관리 도구 등으로 생성하세요. 비밀번호가 저장된 이후에는 `ADMIN_PASSWORD` 대신 저장된 해시로 인증합니다. 저장소 장애·잘못된 인증 데이터는 초기 비밀번호로 우회하지 않고 요청을 거절합니다.

## 데이터와 인증

- 기존 `data/content.json`, `data/inquiries.json`, `data/admin-auth.json` 경로를 유지합니다. 자동 초기화·삭제·운영 데이터 마이그레이션은 없습니다.
- 읽기는 `useCache: false`로 최신 값을 가져옵니다. 쓰기는 ETag 조건부 갱신을 사용하며 충돌 시 최대 5회 최신 데이터를 읽어 재시도합니다. 해결되지 않으면 409로 응답합니다.
- 문의 접수·상태 변경·서로 다른 콘텐츠 필드 변경은 최신 데이터와 합칩니다. 여러 관리자가 같은 콘텐츠 필드 또는 전체 커리큘럼을 편집하면 마지막으로 성공한 저장이 우선합니다.
- 비밀번호 재설정 시 해시·salt가 바뀌어 기존 세션이 모두 무효화됩니다. 이번 변경 전의 구형 쿠키도 무효이며 재로그인이 필요합니다. 세션 수명은 8시간입니다.
- 초기 비밀번호는 저장된 인증 데이터가 **존재하지 않을 때만** 허용됩니다. 운영에서 인증 Blob을 수동 삭제하지 마세요.
- 반복 요청 제한은 비공개 Blob의 `data/rate-limits/`에 분산 함수 간 공유합니다. IP 원문 대신 HMAC 식별자를 저장하고, 해시 버킷별 갱신 때 만료 항목을 제거합니다. 최대 768개 버킷이며, 추가 Blob 읽기·쓰기 비용이 발생합니다.
- 주소별 제한은 로그인 15분/10회, 복구 1시간/5회, 문의 10분/5회입니다. Vercel이 덮어쓴 `x-forwarded-for`만 배포에서 사용하고, 로컬에서는 소켓 주소를 사용합니다. IP를 확인할 수 없으면 공통 제한에 포함합니다. 한 네트워크를 공유하는 사용자는 제한도 공유할 수 있습니다.
- 제한 저장소가 실패하면 요청도 실패합니다. 대량 공격 방어는 별도 Vercel 방화벽 설정으로 보완할 수 있지만, 이 작업에서는 외부 방화벽을 변경하지 않았습니다.

## 콘텐츠 관리

`/admin`에서 제목·연락처·강의 목록을 편집할 수 있습니다. 강의 ID를 유지하며 저장하고, 기존 ID 없는 기본 강의는 상세 URL로 ID를 복원해 표시합니다. 강의 제목·요약·학습 내용·난이도·시간·연락처는 홈페이지와 연결된 상세 페이지에 반영됩니다. 상세 페이지의 추가 정적 문구(추천 대상 등)는 해당 HTML에서 관리합니다.

메인 제목과 소개 문구는 `<br>`만 줄바꿈으로 해석하고 나머지 HTML은 텍스트로 표시합니다. 상세 링크는 HTTP(S) 또는 상대 경로만 허용합니다. 새 강의 항목을 추가해도 상세 HTML이 자동 생성되지는 않으므로 기존 페이지나 별도로 만든 페이지를 연결하세요.

API 장애 또는 JavaScript 비활성화 시 공개 페이지의 기본 안내가 남습니다. 삭제한 강의의 기존 상세 URL은 보존되며, 최신 목록에서 빠졌다는 안내를 표시합니다. 검색 엔진용 정적 설명은 HTML의 기본 내용이고 클라이언트가 로드되면 최신 요약으로 갱신됩니다.

## 검증

```sh
npm run check
npm test
npx playwright install chromium
npm run test:browser
npm audit
```

- `check`: JavaScript 문법, HTML 중복 ID, 로컬 링크·앵커 검사.
- `test`: 실제 API·인증·데이터 모듈을 메모리 Blob으로 검증. 외부 저장소에 접속하지 않습니다.
- `test:browser`: 데스크톱·모바일 Chromium에서 공개·관리자 화면과 실패 상황을 검증. 모든 API 요청은 테스트 데이터로 가로챕니다. 정적 미리보기 서버는 테스트가 시작·종료합니다.
- 브라우저 테스트는 운영 연결 검증을 대신하지 않습니다. 배포 전 개발 환경에서 실제 Blob 권한, 환경 변수, HTTPS 쿠키, 동시 저장, Vercel 경로·보안 헤더를 확인하세요.

## 배포

기존 Vercel 프로젝트를 사용하며 루트 디렉터리는 저장소 루트입니다. 별도 빌드 명령과 출력 폴더는 필요하지 않습니다. 프로젝트의 Node.js 버전을 24로 맞추고 각 환경에 위 변수들을 설정하세요. `vercel.json`에 URL 정규화와 보안 헤더가 있습니다. 소스 수정만으로 배포나 원격 푸시를 실행하지 않습니다.
